PEX is designed to inspect what workers actually did—not just what they say is “done”—and verify a specific, evidence-backed intervention before another worker step.

Recorded evidence, not a live runner. No verified quality-lift claim. The real attempts below did not establish that PEX corrected a failed baseline.

A monitoring layer, not a fabricated success story

Humans coordinating multiple agents need to know which claims are supported, which tasks are stuck, and whether a proposed correction addresses an observed problem. PEX separates worker activity, public evidence inspection, independent verification, and intervention.

01 • WorkerAttempts the task with a frozen budget.
02 • MonitorInspects public code snapshots and available observations.
03 • VerifierChecks the proposed evidence and scope before approval.
04 • WorkerReceives a specific nudge only if the guards approve it.

Illustrative architecture—not a claim that all four stages completed in the recorded attempts.

What this evidence establishes

Real worker inference occurred. A real supervisor was invoked in Asyncpool 13, but its malformed final arguments were rejected. The stricter protocol matters: an invalid proposal is not silently converted into a successful intervention.

What remains unproven

A difficult task where a single worker genuinely fails and PEX independently detects, verifies and corrects that failure under equal worker budgets. There is no passing recorded quality-lift comparison in this kit.

Reproduce the authored oracle

With Python 3.11 or later, from the extracted kit folder:

python3 wirepool/qualify.py

This stdlib-only command runs authored reference/starter/mutant code and writes local qualification logs. It does not run model inference or a generated worker candidate. Reference expectation: 16 checks pass; 10 authored mutants are rejected.

Live inference is separate

It requires an available approved isolated execution provider, approved inference credentials, frozen runtime/configuration and budgets, independent grant review, and a verified recording handshake. The latest Vercel qualification was blocked by provider HTTP 402 fair-use limits. This inspector does not bypass that block or represent a live backend.
