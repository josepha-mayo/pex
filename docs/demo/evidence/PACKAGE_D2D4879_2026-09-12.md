## Packaged and installed behavior

The authenticated packaged-settings smoke passed bridge identity and supervisor
read, returned Zen `muse-spark-1.3-contributor-free` first, retained the default
three-dispatch cap, attached no worker, and made zero provider calls. Its
429-byte receipt has SHA-256
`3edad84235490bcffe86a8791253b836b817415ebdd0d1f7fe1fa2207fe1a285`.
The opt-in frozen-bridge lifetime contract passed 3/3 in 16.09 seconds.

The retained NSIS installer was explicitly targeted at `%LOCALAPPDATA%\\PEX` to
avoid the known same-version no-op behavior. The installed 17,248,256-byte
desktop has SHA-256
`b223762e60d79dfbbc2201ac24d5c01d4b9922778d7392c9808ba3de2b50256a`.
It differs from the canonical desktop in exactly three bytes: the expected Tauri
bundle marker changes from `UNK` to `NSS`. Its desktop-owned bridge answered
`/health/live` with `{\"ok\":true,\"service\":\"pex-bridge\"}`.

A read-only 30-second startup/idle observation settled at ten owned processes.
At 29.58 seconds the full tree held 388,997,120 private bytes (370.98 MiB) and
744,554,496 aggregate working-set bytes (710.06 MiB); the bridge held
125,517,824 private bytes (119.70 MiB). Private memory was falling from its
19.85-second 408,031,232-byte peak, and lifetime CPU increased only 0.3125
seconds from 24.00 to 29.58 seconds (about 5.6% of one logical core). Aggregate
working set can double-count shared WebView pages. This is a moderate footprint,
not a lightweight one, but the bounded sample shows settling rather than runaway
growth or an idle busy loop. It is not a long-duration leak proof.

## Claim boundary

This is the current installable candidate. Package identity, frozen behavior,
startup health, production rendering and bounded resources are verified. Native
pet-window transparency, motion, dismissal, dragging and hide/restore still need
visible acceptance because the automation host exposes no native app surface.
The live OpenCode/Zen/Strands quiet/recovery pair is separate evidence; AgentCore
is locally implemented/tested and not deployed; the comparative benchmark is
unfrozen and has no citeable score.
