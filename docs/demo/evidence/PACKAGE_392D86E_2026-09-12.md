# Two-pet control and final package candidate

Source commit: `392d86e910fc8b969eae82140c8f57b930d8f17d`.

This candidate supersedes `d2d4879`. The overlay no longer renders a detached,
unlabelled close glyph: one `× Hide` control is anchored to the status panel and
remains available when the independently dismissible status message is hidden.
The production pet preview was visually inspected after the repair. Desktop
contracts pass 294 with one intentional Windows symlink skip; the 71-module
production build passes.

## Packaged and installed behavior

The authenticated packaged-settings smoke passed identity and supervisor reads,
selected Zen `muse-spark-1.3-contributor-free` first, retained the default
three-dispatch cap, attached no worker and made zero provider calls. Its 429-byte
receipt has SHA-256
`21b2d8b44c66a33797cebd6e666f07aca527ee666d61840c96dd786096ed7407`.
The exact frozen bridge passed all 3 lifetime/bundle cases in 7.07 seconds.

The NSIS candidate was explicitly installed at `%LOCALAPPDATA%\\PEX`. Installed
SHA-256 is
`e57e57a6df679b4788b504f45a07b76352f9caa7b2cc89afd36604955fb7f058`.
Byte comparison found exactly three differences at offsets 14082698-14082700:
the expected `UNK` to `NSS` marker and nothing else. `/health/live` returned
`{"ok":true,"service":"pex-bridge"}`.

A recursive 61.82-second installed-process sample retained 13 observations and
ten owned processes. Private memory fell from 391,684,096 bytes (373.54 MiB) to
340,955,136 bytes (325.16 MiB); aggregate working set fell from 727,089,152 to
651,255,808 bytes (621.09 MiB). Lifetime CPU advanced 1.40625 seconds over about
61.5 seconds, roughly 2.3% of one logical core. The bridge ended at 126,230,528
private bytes (120.38 MiB). Aggregate working set may double-count shared WebView
pages. This is a moderate footprint, not a lightweight one, but the bounded run
shows settling rather than runaway growth or an idle busy loop; it is not an
hours-long leak proof.

## Claim boundary

Package identity, packaged Zen configuration, startup health, frozen lifetime,
production rendering and bounded resources are verified. Native transparency,
dragging, hide/restore and both-pet motion still require human-visible acceptance.
The live OpenCode/Zen/Strands quiet/recovery pair is separate evidence. AgentCore
is locally implemented/tested, not deployed. The comparative benchmark remains
unfrozen and has no citeable score.
