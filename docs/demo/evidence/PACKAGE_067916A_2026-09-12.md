## Exact installed candidate and resources

Because both local packages use version `0.1.0`, an ordinary silent invocation
initially returned success without replacing the predecessor. This false-success
condition was detected by hashing. Re-running the retained installer with the
standard install path explicitly selected replaced the binary and restored the
uninstall metadata to `%LOCALAPPDATA%\\PEX`.

The installed executable is 17,248,256 bytes with SHA-256
`6a510e8c5dfaf6323133e4227e749bb474ade3173317463e612977cb872e02b5`.
It differs from the receipt's canonical desktop binary in exactly three bytes,
the expected Tauri `UNK` to `NSS` bundle marker. Its desktop-owned bridge answered
`/health/live` with `{\"ok\":true,\"service\":\"pex-bridge\"}`.

The exact installed process tree settled at ten processes. From 24.54 to 60.08
seconds, private memory moved from 395,448,320 to 395,829,248 bytes (+0.36 MiB),
aggregate working set from 742,277,120 to 753,152,000 bytes (+10.38 MiB), and
lifetime CPU from 17.4375 to 18.8125 seconds (about 3.9% of one logical core over
that interval). Final private memory was 377.49 MiB; the bridge was 122.29 MiB.
Aggregate working set can double-count shared WebView pages. This footprint is
moderate rather than tiny, but the settled window does not show runaway growth
or an idle busy loop. It is not an hours-long leak proof.
