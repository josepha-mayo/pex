# Legacy eight-pet browser captures

These files show the retired sparse browser-only interface with eight pets and
Hatch/Import controls. They are retained only as historical design evidence.

Do not use any file in this directory in the Devpost gallery, public README,
demo video or current-package acceptance. The shipping MVP contains exactly Pex
and Von. Fresh visual evidence must be captured from package source `56783bf`
after its bounded native acceptance passes.

The two WebM files are byte-identical 6.84-second captures (920×700, VP8), both
with SHA-256
`660c9b287489d20f0853796d09c89745c95d4763ed28e5c23db8017fb7a50ef2`.
